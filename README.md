## Purpose
This repository stores the LITESTAP program code only.

## Important data rule
Do not upload accounting data, company financial records, bank statements, PDFs, Excel/CSV exports, backups, LITESTAP_DATA.json, or Month_Data.json to GitHub.

## Browser storage model
The GitHub-hosted index.html can be opened in a modern browser. The user selects a primary working folder such as C:\LITESTAP, plus optional Google Drive/Desktop and USB backup folders. Browser security still requires explicit folder permission.

## Backup design
- Immediate browser recovery copy
- Primary local working folder
- Automatic backup attempts every 30 minutes while the page remains open
- Manual Back Up Now action
- Emergency JSON download

## Accounting structure
Company → Bank Account → Tax Year → Month, with separate Bank Statements, Exports, Backups, and Month_Data.json folders/files.

LITESTAP is an accounting organization and recordkeeping tool and is not a substitute for professional accounting, tax, payroll, or legal advice.
